# hackathon-learnings

A collection of training materials and resources developed during hackathon sessions. This repo covers hands-on learnings across the Databricks platform.

## Training Tracks

### Fundamentals
Core platform concepts, workspace navigation, basic notebooks, and Databricks One.

### Data Analyst
SQL analytics, dashboard creation, data exploration, and reporting techniques using Databricks SQL and AI/BI.

### Dev Tools
Development workflows, version control, CI/CD, Declarative Automation Bundles, IDE integrations, and productivity tooling.

### Apps and Agents
Building Databricks Apps, AI agents, Genie spaces, and leveraging generative AI capabilities within the platform.

## Getting Started

1. Clone this repo to your Databricks workspace
2. Navigate to the training track relevant to your role
3. Follow the notebooks in order within each track
